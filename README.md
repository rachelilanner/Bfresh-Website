Bfresh Demo Website
Overview

This project is a full-stack demonstration website inspired by the Bfresh drinks and soft-serve store. 
It was developed for educational purposes to demonstrate full-stack web development concepts, including frontend development, backend APIs, database integration, and administrative functionality.

Disclaimer: This is not an official Bfresh website. It is an independently developed educational project and is not affiliated with or endorsed by Bfresh.
